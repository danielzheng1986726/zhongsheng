# 给编辑的预热消息

> 发送时机：她说会「今天或明天上午」定采访时间，你可以在她发提纲之前主动发这段
> 发送方式：微信，语气轻松自然

---

## 消息正文

嗨老师，上次聊完我又回去想了想，有几个故事碎片先发你，方便你写提纲的时候参考：

1. **比赛第四天的崩溃时刻**——我建了 115 人的微信群，每天发内容、做搞笑视频、发红包，觉得稳了。结果第四天晚上打开后台，实际登录只有 17 个人。因为前三天我没设登录墙，大家看完就走了，后台一个数据都没留下。那个数字 17 我记得特别清楚。

2. **即兴喜剧 → 众声**——这段上次讲了一半。完整版是：即兴喜剧的创始人们想了很久怎么定协作规则，最后发现问题不是「怎么合作」而是「怎么停止否定对方」。所以从 Don't say no 变成了 Yes, And。众声的核心逻辑一模一样——不是消灭分歧，是在分歧里找到「其实你们想的是同一件事」。

3. **意外的反转**——39 个用户，第一名 1007 个，差 26 倍。我以为彻底完了。结果收到了两张奖状。然后就有了和你们的这次对话。

你上次说的那句「没什么技术背景但就是很想赢」确实是我当时最真实的状态哈哈。随时可以约时间聊～

## 补充说明（不发给编辑，自己看）

- 这三个故事分别对应：**挫折画面感** + **产品理念深度** + **反转高潮**，帮她把采访提纲的叙事弧线搭起来
- 主动给素材 = 让她写出更好的问题 = 你的采访质量更高
- 最后一句接她原话，拉近距离
- 播客的事先不在消息里提，等正式聊的时候当面推进更自然
