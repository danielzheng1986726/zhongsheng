# Zhongsheng Public Metrics

Status: canonical wording for public or semi-public Zhongsheng hackathon storytelling.

Last updated: 2026-07-08.

Use this file before publishing, pitching, or reusing old MOOK / hackathon / build-in-public material. Older drafts may contain partial numbers from different moments in the competition.

## Canonical Numbers

| Metric | Canonical wording | Use case |
| --- | --- | --- |
| Community reach | 115 people joined the WeChat group | Use when describing distribution effort. |
| Day-four login shock | Only 17 people had logged in when Daniel checked the dashboard on day four | Use as the story beat about the missing login wall. Do not describe this as the final user count. |
| Final users | 39 users by the end of the competition | Use for final hackathon result and comparison with the first-place team. |
| Result | Did not enter the final by user count, but won Zhihu Special Award and Zhihu User Choice Award | Use for the reversal / lesson. |

## Writing Rule

Do not compress the story into `17 users` unless the sentence clearly says it was the day-four dashboard moment. For final results, write `39 users`.

When writing the lesson, use the full sequence:

```text
115 people joined the group -> day four showed only 17 logins -> final result was 39 users -> the product still won two awards.
```
