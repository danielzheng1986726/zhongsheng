## 9. 重要工作约定（user preferences）

### 写作风格
- **画面感优先**：「深夜看到数字 17」> 「用户转化率低」
- **故事代替总结**：编辑要的是人和动机，不是产品介绍
- **保持克制**：刷量背景写但不点名，复盘文不变成研究报告

### 文档习惯
- 项目文档放 `docs/`，宣传素材放 `promo/`
- HANDOFF 文档命名：`HANDOFF-YYYY-MM-DD.md`
- 复盘和行动计划是分开的两份文档（不要混）

### Git 习惯
- 用户说「收工」= 记忆更新 + commit + push
- Commit message 用英文，简洁说明 why 而不是 what
- 永远新建 commit，不 amend

### 沟通风格
- 中文为主，技术词保留英文
- 不要堆 emoji
- 直接给方案，不要列「优点缺点」式的废话
